# Animated Time-Series Graph

This module demonstrates the construction and export of an animated time-series visualization with Matplotlib. It is a visualization example rather than a physical model; the assumptions and provenance of any substituted dataset must be documented separately.

The notebook is the source, while `ts_animation.gif` and `ts_animation.mp4` are rendered outputs. MP4 export requires `ffmpeg`.
