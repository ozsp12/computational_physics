# Statistical Distributions

This module generates and visualizes common probability distributions. It is intended as a computational reference for connecting probability mass or density functions with finite numerical samples and empirical plots.

The notebook should be interpreted with the distinction between a theoretical distribution and a finite random sample kept explicit. Random seeds, sample size, binning, and plotting range can materially affect the displayed result.
