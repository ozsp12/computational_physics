# Computational Physics: Lecture Notes and Tutorials

This repository is a personal collection of computational physics notes, numerical experiments, Jupyter notebooks, simulations, animations, and supporting bibliographic material. The examples connect physical models with numerical analysis, scientific programming, statistical methods, visualization, and machine learning.

The repository is not intended to be a software package or a single linear course. Each folder is a self-contained teaching unit that can be read independently.

## Types of material

The repository contains:

- Jupyter notebooks with theoretical explanations and executable code;
- numerical solutions of ordinary differential equations;
- statistical and data-analysis demonstrations;
- scientific visualizations and animations;
- examples connecting physical models with machine learning;
- bibliographic material on computational physics, numerical analysis, optimization, and matrix computation.

The notes may be written in English or Portuguese, depending on the original audience and purpose of each teaching unit.
