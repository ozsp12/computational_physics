# Evaluation of LLM-Generated Scientific Reasoning

This directory contains comparative figures used to examine responses generated by large language models for mechanics and calculus questions. It is a methodological study adjacent to computational physics, not a benchmark with inferential validity unless prompts, model versions, sampling settings, evaluation criteria, and independent replications are reported.

The images are retained as documentary artifacts. Conclusions drawn from them should distinguish mathematical correctness, explanatory quality, and presentation quality.
